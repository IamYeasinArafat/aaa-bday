# Bday — for Adiba 🌸

Personal birthday site for Alima Asad Adiba (AAA). Plain HTML/CSS/JS — no build
step, no framework. Open `index.html` directly or serve the folder with any
static server (e.g. `python3 -m http.server`).

## What's inside

- `index.html` — hero, letter, No Contact Break, Hall of Fame, "The Y.V.A.
  Collection" gallery, finale
- `style.css` — pink/lilac theme, polaroid cards, sakura canvas
- `script.js` — `CONFIG` block at the top (name, birthDate, gallerySize);
  live age counter, gallery shuffle, confetti, Hall of Fame arrows, petals
- `img/1.jpg`–`img/8.jpg` — Hall of Fame photos with captions aligned to
  Adibenku (keep numbering matched if you ever swap them)
- `img/gallery/1.jpg`–`16.jpg` — Y.V.A. Collection gallery
- `img/no-contact-break/break-no-cont.png` — No Contact Break section image

## Notes

- The Hall of Fame cards are static HTML — edit them directly in
  `index.html`, keep `img/N.jpg` numbering contiguous.
- To change her name or birthday, edit the `CONFIG` in `script.js`.
